# Lantern Moth

A one-tap pixel-art arcade game for mobile browsers. Guide a tiny moth up a dark
chimney, collect sparks to keep the lantern lit, and climb as high as you can.

**Play:** open `index.html` in a browser. It's a single file with no build step
and no dependencies. To play on a phone, host it anywhere static (for example
GitHub Pages).

**Controls:** tap anywhere (or Space / Up arrow) to flap. Tap the speaker icon
(or press M) to mute.

See [GAME_DESIGN.md](GAME_DESIGN.md) for the design.

## Lantern Moth II (roguelite)

`v2/index.html` is a separate roguelite version. It is still one-tap play, but
every 200 m you pick one of three gifts: auto-firing weapons (Ember Bolt, Flame
Ring, Glow Nova) or passives (shield, magnet, brick smashing, revive and more).
Wax earned each run buys permanent upgrades, saved on your device.

## Lantern Moth II Hold (variant)

`v2-hold/index.html` is Lantern Moth II plus a hold action. Tap to flap as
before. Keep your finger down to stop zigzagging and glide straight down
slowly, so you can line up with a gap. Release and tap to climb again.
